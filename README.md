# ShineX Infra — client preview site

Static site. Open `index.html` in a browser, or serve the folder.

## Pages
- Home `index.html`
- Work / Studies `work/`
- Services (3) `services/`
- Process `process/`
- Studio `studio/`
- Contact `contact/`

## Local preview
```
cd shinex-infra-website
python3 -m http.server 8080
```
Then open http://localhost:8080
